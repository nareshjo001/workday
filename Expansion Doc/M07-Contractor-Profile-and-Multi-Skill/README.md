# M07 — Contractor Profile & Multi-Skill

M07 replaces the former single-skill staffing model with a normalized skill catalog and contractor-skill records. Contractors can describe a professional headline, phone number, total experience, and multiple skills with proficiency and experience. Staffing matches any active recorded skill; the primary skill is presentation only.

Before M07, one nullable enum field created false staffing shortages. After M07, Vendors can filter their contractor list by any skill and staffing eligibility uses the relationship table. Contractors, Vendors, and future staffing workflows benefit. JWT ownership, tenant scoping, historical assignments, and immutable financial records remain unchanged.
