# M15 — Rate Cards, Assignment Rate Snapshots & Rate History

M15 separates Vendor–Client commercial bill/cost rates from contractor legacy/default hourly rates. Every accepted assignment stores a rate-card snapshot, so later commercial changes cannot rewrite assignment history.

Rate cards are scoped to one active Vendor–Client relationship and skill. Their inclusive effective dates determine which card is used for a new candidate acceptance. Cost rates are commercial inputs only and are never returned in PM project-team responses.
